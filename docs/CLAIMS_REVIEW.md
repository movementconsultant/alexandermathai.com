# Claims review — alexandermathai.com (Mark 2)

**This is an owner decision artifact. It is not a factual endorsement, and it is not a source of
truth for live public copy.** It was generated by reading every content source that can affect
rendered output (`src/pages`, `src/components`, `src/content`, `src/data`, `src/layouts`, RSS,
JSON-LD) and extracting every numerical/statistical claim, historical date/timeline assertion,
organization/brand/client/product/proper-name assertion that could reasonably be read as a factual
credential, and any such claim appearing in visible copy, metadata, or structured data. No claim
below has been independently verified — this build environment has no general web access, and
nothing here was confirmed against an external source. Checking a box does not change the live
site.

Companion machine-readable version: `claims.registry.json`. Schema and governance model:
`docs/claims-governance.md`.

## How to review

- Each item below has a **Decision** checkbox (`Approve` / `Qualify` / `Remove`) for the owner to
  mark. Leaving a box unchecked means no decision has been made yet.
- **Checking a box here does not alter the live site.** Applying an approved, qualified, or
  removed claim to actual page copy is a separate, explicit editorial pass — this document only
  records the decision so that pass can be scoped and reviewed.
- "Repository evidence" means a source file in this repository that substantiates the claim (a
  document, a dataset, a prior confirmed record) — not the data file that merely states the claim
  as a UI value. Almost none of the claims below have this; that's expected for founder-reported
  biography and business facts, and is not itself a defect.
- 40 of the 41 claims below are marked pending. Exactly one (`work-tmi-ecosystem-self-reference`)
  is self-evidently true from this repository alone and needs no owner sign-off.
